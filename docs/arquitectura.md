# Arquitectura de MatchGrid API

## Estado

Semana 2 — En desarrollo

## Servicios principales

1. Usuarios y Autenticación
2. Torneos
3. Equipos e Inscripciones
4. Partidas y Resultados

## Comunicación

Los servicios utilizarán APIs REST con intercambio de información
en formato JSON.

## Roles

### Organizador
Responsable de crear y administrar los torneos,
supervisar partidas y resolver disputas.

### Capitán / Jugador
Responsable de administrar su equipo, realizar inscripciones,
hacer check-in y reportar resultados.
