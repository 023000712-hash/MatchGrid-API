# MatchGrid API

## Proyecto Integrador — Arquitectura Orientada a Servicios

MatchGrid API es una plataforma orientada a servicios para la
gestión de torneos y emparejamientos comunitarios.

## Descripción

El proyecto busca automatizar y centralizar la gestión de torneos
comunitarios, reduciendo la dependencia de herramientas separadas
como formularios, hojas de cálculo y canales de comunicación.

## Objetivo

Diseñar y desarrollar una API REST orientada a servicios que permita
gestionar usuarios, torneos, equipos, inscripciones, check-in,
partidas y resultados.

## Servicios principales

- Usuarios y Autenticación
- Torneos
- Equipos e Inscripciones
- Partidas y Resultados

## Tecnologías

- Node.js
- Express
- PostgreSQL
- REST API
- JSON
- Swagger / OpenAPI
- Postman
- Git / GitHub
- Docker
